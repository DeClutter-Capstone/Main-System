┌─────────────────────────────────────────────────────────────────────────────────┐
│  THE FLOW (SIMPLE)                                                              │
└─────────────────────────────────────────────────────────────────────────────────┘

    👤 USER ACTION
         │
         ├─ Uploads image (JPG/PNG, max 5MB)
         ├─ Selects room type (Bedroom, Living Room, etc.)
         ├─ Selects style (Minimalist, Modern, Scandinavian)
         └─ Clicks "Generate" button
              │
              ▼
    📱 FRONTEND SENDS REQUEST
         │
         └─ POST /api/transformations/
            ├─ image_file: File
            ├─ room_type: "bedroom"
            └─ style_name: "minimalist"
                 │
                 ▼
    🖥️  BACKEND PROCESSES
         │
         ├─ Reads image bytes
         ├─ Converts to base64 data URL
         ├─ Saves transformation record
         └─ Calls Replicate API
              │
              ▼
    🤖 REPLICATE AI PROCESSES
         │
         ├─ Receives image + room type + style
         ├─ Processes through AI model (30-60 sec)
         └─ Returns output image URL
              │
              ▼
    🖥️  BACKEND RETURNS RESPONSE
         │
         └─ JSON with output_image_url
              │
              ▼
    📱 FRONTEND DISPLAYS IMAGE
         │
         └─ Generated image shown to user
              │
              ▼
    👤 USER SEES RESULT
         │
         ✅ Bedroom transformed to selected style

  REQUEST:
  ┌─────────────────────────────────────────────────────────────────┐
  │ POST /api/transformations/                                      │
  │ Content-Type: multipart/form-data                               │
  │                                                                  │
  │ Parameters:                                                     │
  │   • image_file: File (required) - JPEG/PNG, max 5MB             │
  │   • room_type: string (required) - e.g., "bedroom"              │
  │   • style_name: string (required) - e.g., "minimalist"          │
  │   • project_id: string (optional)                               │
  │   • input_image_id: string (optional)                           │
  └─────────────────────────────────────────────────────────────────┘
